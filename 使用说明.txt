发票汇总助手 V1.1.22

界面提示
- “签名管理”使用扁平页签及蓝色底线，默认打开“签字位置”；验收单、领用单分成两张卡片，各并排选择两个签名。签名库页用列表/预览双卡片展示，导入等工具在顶部，重命名/替换/删除在下方；窄窗口上下排列。导出时可添加签名，原 Excel 不添加签名。
- 任务栏和窗口图标按 Windows 当前显示缩放选择尺寸；图标包含常用缩放对应的独立图像，保留原有图案。
- 首次选择输入显示“等待只读预览”；本次软件会话已完成过预览后，更换输入或使结果失效时显示“需要重新预览”。品牌标题下副标题及三个主操作按钮同行的辅助小字已移除。
- 两条路径左侧提供“选择 PDF 文件夹”和“选择目标工作簿”高亮按钮，可反复选择。预览通过后路径框锁定，原按钮改为描边；点击后确认改选，只有选中不同路径才清除当前预览、校正及导出资格，取消或选择原路径保留结果。预览异常／无需处理、PDF 导出成功后恢复路径编辑；处理中与选择窗口期间不可选择。
- 直接进入发票处理页，没有选项卡栏及规则更新入口。规则由维护者随完整软件包提供，详细操作见本文件。
- 右上角显示实际软件版本号；识别版本见只读预览报告。
- 滚动条自动隐藏：内容溢出时，鼠标移入或滚动会显示，停止活动约1.4秒后隐藏；滑块上悬停或拖动时保持可见。隐藏与显示不改变内容区域。
- 底部细线在处理中呈蓝色渐变流动，结束后停止；当前步骤和实际结果以阶段卡及页面数据为准，异常或需注意的情况会弹窗。
- 主操作使用独立圆角按钮和本地图标：放大镜为“只读预览”，播放图形为“执行处理”，文件导出图形为“导出 PDF”。有悬停、按下和键盘焦点反馈。
- 同一行的前三个按钮（只读预览、执行处理、导出PDF）为工作流程，后四个（签名管理及三个打开按钮）为辅助功能，中间有竖分隔线；分组边界换行时改为横线。窄窗口自动换行，入口可用条件保持原样。
- 独立人工校正按钮已移除；预览有可校正明细时，明细标题旁以浅金背景、铅笔图标及加粗文字提示“双击明细，可人工校正”。未预览、处理中、恢复未完成任务或预览失效时显示对应状态。
- 预览固定为浅蓝描边；执行可用时为深蓝实心，不可用时为浅灰描边，处理中按钮显示“正在预览…”或“正在处理…”。
- 四项摘要显示本次发票数、明细数、金额和人工校正数；未预览时显示占位符。
- 明细使用交替底色，人工校正行淡黄色并标明“已校正”；全部表头和内容统一左对齐，包括序号、单位、数量、单价、金额与校正标记。
- 明细列按参考截图比例随窗口缩放，宽度足够时文件名约19%、产品名称约18%、规格约7%、厂家约19%。各列保留最低宽度，较窄窗口可横向滚动。可拖动表头列边界，调整后的比例在本次软件会话中保留；重启恢复默认比例。
- 各阶段的提示卡仅显示大标题，保持左对齐、上下居中，通过标题和背景颜色区分状态；正常完成不再单独弹窗，异常弹窗显示简短原因并可复制完整诊断。

==================================================
执行步骤
==================================================
1. 解压整个软件目录，保持 InvoiceSummary.exe、_internal 和 recognition 文件夹在同一个目录。
2. 双击 InvoiceSummary.exe。
   普通使用者直接使用随包规则，无需安装 skill、绑定来源或先做同步。
3. 点击路径框左侧两个蓝色按钮，选择包含完整批次发票的 PDF 文件夹及目标 .xlsx 工作簿。
4. 点击“只读预览”，查看文件名、明细、金额、模板检查和异常。
5. 字段有误时，双击需要修改的明细，或选中后按 Enter；保存后软件会重新检查。其他异常解决后重新预览。
   预览通过后点击“执行处理”，清空旧明细并按完整批次重填，等待完成。
6. 等待主页面显示“执行处理完成”；金额验证或临时文件清理有问题时会弹窗。开始下一批处理前再重新预览。
7. 本次执行处理及金额核对成功后，“导出 PDF”才会启用，选择保存位置导出。完成后点击“打开导出目录”；需要 PDF 时请先导出，再开始下一次预览。

【执行会重命名 PDF，清空两表全部旧明细（含品牌、备注）后整批重填；原位更新，不自动创建备份。】

1.1.9 起，正式写入时“领用日期”为本机当天，“验收日期”为前一个日历日，格式为 YYYY.M.D；只读预览不会保存日期。

==================================================
必要条件
==================================================
1. Windows 10/11，已安装 Microsoft Excel 桌面版。无需安装 Python 或 Node.js；软件离线运行。
2. 完整解压软件文件夹，保留 EXE、_internal 和 recognition；软件所在目录须可写。已导入签名时，转移软件需一并保留 signatures 文件夹。
3. 使用有文本层的电子发票 PDF，不支持扫描图片 OCR。每次选择完整批次；目录中没有的旧明细将移除，旧表人工修改不会保留。
4. 工作簿为 .xlsx，包含“验收”“领用”两张表。两表均有完整表头、日期标签和唯一“合计—签字—说明”三行页脚。
5. 执行前关闭 Excel 中的目标工作簿；发票和工作簿所在目录须可写。

阶段完成提示
- 操作按钮下方的阶段卡显示当前阶段与结果；正常完成不弹窗，有异常时显示中文原因并可复制完整诊断。蓝色表示处理中，绿色表示通过，黄色表示预览异常或清理提醒，红色表示操作未完成。
- 只读预览、执行处理及PDF导出顺利完成时只更新主页面，不再弹出完成提示。异常、跳过非发票文件及清理提醒仍弹窗。
- “预览完成”表示检查结束；只有“预览通过”才可以执行。有异常时明确提示暂不能执行。
- 执行失败会显示原因；填表与金额核对完成但临时文件清理失败时，另行提示清理问题。
- 人工校正检查正常时只更新页面提示，有异常时弹出中文原因和“复制错误信息”按钮。更换输入或更新规则后须重新预览。
- 主页面不再显示详情入口或报告区域，空间用于发票明细。异常弹窗显示简短中文提示，点击“复制错误信息”可复制该次提示的完整诊断和处理记录；正常完成只更新主页面，不再弹窗。未知原因可复制后反馈给维护者。阶段标题和细线进度条保留。
- 各类弹窗以当前主窗口为居中参考，最大化时也采用相同策略；必要时调整到主窗口所在显示器的可用区域内。弹窗打开后仍可自行移动。

非发票 PDF 自动跳过
- 随包新版共享规则按内容判断，只有明确识别的验收单、领用单、送货／出入库单等非发票才跳过；不根据文件名或“解析失败”猜测。查验报告也仅作跳过说明。
- 跳过文件保持原样，不占发票序号，不改名、不填表、不计入发票数量和金额。
- 存在跳过文件时，预览和执行仍弹出提醒，列出跳过数量、完整文件名及原因，可滚动查看。跳过本身不作为阻塞异常。
- 扫描件、损坏文件、无文本／类型不明页面以及疑似发票缺少字段仍提示异常，须处理后重新预览。目录没有可处理发票时禁止执行，不清空工作簿。
- 分类依据随包skill共享规则，弹窗和报告由软件维护；识别改进由维护者发布新版软件包提供。

导出 PDF（只在软件中进行）
- 点击独立的“导出 PDF”，分别生成“验收单.pdf”和“领用单.pdf”。默认工作簿旁的“导出PDF”文件夹，可选择其他位置；同名文件确认后才替换。
- A4 横向，所有实际内容列放在一页宽，明细较多时向下自动分页；包含标题、备注、签字、说明和右侧模板文字。导出完成后阶段卡显示“PDF 导出完成”，可点击“打开导出目录”查看文件，不再单独弹出成功提示。
- 仅本次执行处理并通过逐票及批次金额核对后启用；仅选文件、预览或人工校正均不能导出。执行失败或无需处理不启用；金额已通过但临时文件清理有提醒时仍可导出。
- 更换输入、重新预览、已使用规则更新或重启软件后，须重新预览并执行成功。导出前确认工作簿仍与该次完成版本一致，外部修改或文件丢失时停止导出并要求重新处理。
- 取消导出、普通导出失败及成功均保留本次资格，可以重试或重复导出。
- 填表后由Excel原生自动列宽统一适配所有明细列，包含表头及合计数字，保留原列宽和行高下限；达到列宽上限时换行。使用未合并的标准明细区，标题和页脚合并保持；容量不足或错误值会停止发布排版副本。
- 导出时将最后一条明细及其下方的合计、签字和说明作为同页组。先尝试最多约5%的额外缩放，空间仍不足则整组移至下一页；整组超出单页容量时提示原因并停止。
- 使用本机 Excel 在临时副本中设置打印参数；原工作簿保存完整显示所需的换行和行高，不保存导出用的临时分页设置。页边距及重复表头保留；未设置重复表头时重复标题至表头行。
- 优先在本次独立 Excel 中使用已安装的 Microsoft Print to PDF，避免部分虚拟打印组件放大纸张；结束时恢复 Excel 原打印机，不改变 Windows 默认打印机。没有可用的 Windows PDF 打印组件时沿用原组件，仍检查实际页面尺寸；尺寸异常会给出实测值和处理建议。
- 两份 PDF 都生成成功并检查后才替换；失败时恢复旧文件。恢复未完成时保留恢复目录及备份，请按报告路径核对。
- 导出失败不清空当前预览或人工校正，可解决原因后重试。导出功能随软件维护，skill 更新不会改变该功能。

人工校正（只在软件中进行）
- 预览完成后双击需要修改的明细，或选中后按 Enter；双击表头及空白不会打开校正窗口。
- 对照原 PDF 校正产品名称、规格型号、单位、数量、含税金额和生产厂家，单价自动计算。弹窗显示原始识别值和当前值，可直接“打开原发票”。
- 点击“保存并检查”只更新本次预览，不改 PDF、工作簿或 skill。检查通过后才可执行。
- 校正明细会高亮，检查结果显示修改前后值。“恢复识别值”可撤销该行校正。
- 名称和生产厂家不能为空；规格和单位可空。数量空白按 1，非空须为有效非零数字；金额最多两位小数，逐票和批次合计仍须与原票一致。
- 仅限已有明细的字段；不能新增或删除明细、改序号、改票面总额。漏项、多项、整票解析失败等问题需在 skill 中改进。
- 正式填表使用本次预览及校正后的全部明细，替换两表全部旧明细；不再要求旧表业务值与识别值一致。
- 校正只对本次预览有效；重新发起普通预览会重新识别，需要再次校正。执行中断的校正会随本机恢复记录保留，恢复期间先完成上次运行，再进行新的人工校正。
- 有校正时，预览按钮标明“清除校正”；重新预览、更换输入路径、更新规则或关闭软件前会提示，选择“否”保留原预览和校正。保存校正后已自动检查，不必再次点击预览。
- 恢复记录中的校正已持久保存，不误报为关闭即丢失。失败操作会保留仍对应当前规则的原预览；重试时继续检查输入和规则。

处理异常与恢复
出现识别异常、重名、金额不符或页脚异常时，处理问题后重新预览。
如果 Excel 操作或金额验证失败，解决原因后重新选择同一批次和工作簿进行只读预览，可继续未完成的处理。关闭并重启软件后仍可恢复。恢复期间请保持发票内容及识别版本一致。

功能归属与更新边界
- 与 skill 保持一致：PDF 识别、字段规范化、折扣与运费、排序和文件名、金额核对，以及对应的字体／重算和金额采集脚本。
- 软件独有：人工校正、执行前清空旧明细并整批重填、完成提示、中断恢复、验收与领用 PDF 导出、界面操作和便携分发。这些功能随完整软件版本维护。
- 共同约定：字段含义、金额精度、序号、表头、三行页脚、日期、单价和合计，以及脚本输入输出接口。约定不兼容时停止更新，须适配并升级软件。
- 软件流程：识别 → 可选人工校正 → 重新检查 → 正式执行时清空整批重填 → 写后金额复核。人工校正不回写 skill。
- 完整分工详见软件目录中的“功能归属与更新边界.txt”。

普通用户：解压即用
- 完整解压整个发布包后直接运行，按“执行步骤”处理发票；使用软件携带的规则即可。
- 无需安装或绑定本机 skill，不需要先同步或导入规则包。请保留 _internal 和 recognition 两个文件夹。

规则版本与新软件包
- 软件仅使用随包规则，不提供选择skill、同步、导入、导出或回退入口。
- 规则由维护者更新并准备到完整软件包中；需要识别改进时联系维护者获取新版。
- 新版应在新文件夹完整解压，保留整个 _internal 和 recognition，不能只替换或转发EXE。
- 识别版本在实际只读预览报告中显示；规则损坏时重新完整解压软件包，或联系维护者获取新版。
- 旧软件记录的本机skill来源绑定不再读取或监测，不会因维护者路径失效阻止处理。既有业务恢复记录保留。

工作簿约定
- .xlsx 文件须含“验收”“领用”工作表及规定表头、明细格式行、日期标签和唯一“合计—签字—说明”三行页脚。
- 折扣、运费合并和字段规范与 skill 对应；同键重复明细保留，空数量按 1。
- 只读预览不保存或清空原表；正式执行在暂存工作簿中清空、重填，然后原位替换目标文件。
- 清空范围为表头之后、合计之前的主表明细区域，列范围按完整表头界定；主表里的值、公式、批注、超链接、品牌和备注一并清除。
- 主表右侧“第二联：财务报销”等模板文字保留，分成多个单元格也保留原位置和样式；增减明细行时继续保护，保存时复验。预览报告显示保留的单元格数量。
- 当前随包模板规则使明细区至少保留到完整侧边标识最后一个字的实际所在行，不写死第 13 行；项目较少时保留必要空行的格式、边框和行高，合计位于保留区之后。预览显示最低保留行、必要空行数和合计行。
- 新模板规则要求右侧文字为固定值；若右侧模板有公式，预览报告具体单元格并停止，请将其改为固定文字后重新预览。
- 如果源模板的合计已经位于侧边标识结束行或其上方，预览停止并报告两个实际行号；请恢复完整模板后重新预览。没有完整标识时按实际明细收缩；旧快照沿用其既有删行行为。
- 旧版本已经删除的模板文字不会自动补回；请手工补回文字或使用文字完整的模板。软件不从其他工作簿自动覆盖模板。
- 按预览顺序连续重填全部明细；保留格式、表头、其他工作表、签字及说明页脚，并按明细数量调整数据区。
- 旧明细与本次识别结果不同不会阻塞；识别异常、金额不符、重名、模板不完整仍会停止。
- 明细和页脚移动时维护公式引用；不支持的动态公式或命名区域会在预览阶段提示，需调整模板后再处理。
- 需要增减明细行时，含 Excel 表格、筛选、条件格式、数据验证、透视表、图表、图片或手动分页的工作表会提示调整模板；工作簿或任一工作表的命名区域，以及涉及移动区的重复打印行、冻结窗格和超链接也会阻塞。
- 验收单价保留公式，领用单价写入计算值；两表总额逐分核对。

源码维护工具由维护者使用。识别规则保存在软件目录的 recognition 中，未完成业务运行记录保存在本机 AppData\Local\InvoiceSummary\instances 中；业务恢复记录不会随软件文件夹分发。旧skill来源绑定不再读取或写入。

签名库与 PDF 签名（1.1.20 起）
==================================================
1. 点击“签名管理”→“签名库”→“打开签名文件夹”，把 PNG、JPG、JPEG 放入 signatures\签名图片，文件名去扩展名就是标签（例如“张三.png”显示为“张三”）。打开管理或点击“刷新列表”后自动加入；也可用“导入签名”按钮，标签默认取原文件名。
2. 在默认的“签字位置”选项卡中，为四个位置的下拉框选择标签：验收单经办人／验收人、领用单保管人／领用人。同一标签可复用；不需要签名的位置选择不使用签名。点击“保存”后位置选择才生效，右上角关闭不保存未提交的位置选择。签名图片的导入、重命名、替换和删除在操作成功后保存。
3. 在软件里更名会同时更改图片文件名并保留位置关联；软件内替换图片或删除已使用签名前会列出受影响位置。直接在文件夹改名、删除或同名替换时，原关联会清除并标为“需确认”，须重新选择标签或明确选择不使用签名后才可带签名导出。
4. 本次执行成功后点击“导出 PDF”，核对列出的签名标签并勾选“添加已保存签名”；取消勾选则导出无签名 PDF。导出窗口也可进入签名管理。
5. 软件按实际 PDF 标签动态定位，四处共同约束最小可用尺寸框，签名紧跟冒号、上下居中，并保持图片原长宽比例。明细变化和分页不会采用固定行号或页面坐标；签名只出现在签字栏所在页。
6. 原 Excel 不添加图片；签名在暂存 PDF 中加入，检查两份文件完成后再保存。位置不明确、区域已有内容或图片缺失时，会停止带签名导出并说明原因。
7. 活动图片在 InvoiceSummary.exe 旁的 signatures\签名图片，config.json 保存四处位置选择。转移个人软件时复制整个 InvoiceSummary 文件夹；删除软件目录外的导入源图片不影响已保存签名。旧版签名自动迁移，旧UUID图片及配置保留备份，不必重新录入。
8. 建议导入笔迹清晰、空白少的图片；软件保守裁去可识别的纯白／透明外围空白，保持笔迹，不处理拍照阴影或复杂背景。
9. 多个软件窗口同时修改时会提示刷新或重试；导出按窗口显示的配置核对后固定签名快照，处理中不能修改。公开发布包与源码包不包含个人签名，接收者自行导入。
10. 页签导航、卡片及字段使用主界面配色，页面滚动条自动隐藏且独立保留位置；滚轮不会改变签名标签。点击页签或用方向键、Ctrl+Tab切换，不重新扫描图片、不保存或丢弃未保存的位置选择，仍需点击底部“保存”。已有警告在默认页也能查看。
11. 标签不区分大小写；“张三.png”和“张三.jpg”属于重名，须只留一个或改成不同标签。重名、损坏或空白图片会列出原因并跳过，不会随意选用。只扫描图片文件夹本层，不扫描子文件夹。预览和导出在内存中处理外围空白，直接放入的照片保持原样。
12. 管理窗口在后台读取列表和签名预览，快速切换时只显示最后一次选择。刷新或保存期间相关操作暂不可用，等待底部状态完成后继续；保存期间请等待完成后关闭窗口。软件缓存相同图片的处理结果，导出前仍重新核对实际文件内容。
