# 导出签名风格 Implementation Plan

**Goal:** 使导出窗口的选择框和弹出列表滚动条与主界面一致。

**Architecture:** 增加局部Combobox弹出样式辅助类，保留Tk原生弹出列表及交互，仅配置其颜色、无箭头滚动条布局和可见状态。导出签名面板安装辅助类并补全字段焦点/边框样式。

**Global constraints:** 版本1.1.24；不改签名库和导出算法；不新增/运行测试；不修改个人签名或识别规则；仅本地交付。
