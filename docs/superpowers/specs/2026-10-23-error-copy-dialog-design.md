# 主页面取消详情，异常弹窗复制诊断

用户批准取消主页面“查看详情”，把空间留给发票明细。异常弹窗保留简短中文原因/建议和“复制错误信息”，正常完成只显示结果。

彻底删除主页面的报告控件、展开和复制入口。原始处理记录改为App中的普通字符串，保持预览/金额/跳过文件/改名/页脚/导出/恢复记录的内容及业务状态不变。主表保持唯一可伸展的主内容区，不为诊断预留行或高度。

新增与主界面同主题的结果模态窗口：中文消息在可滚动的只读区域，底部确认按钮固定可见；异常/警告另有“复制错误信息”按钮，复制弹窗创建时冻结的原始记录及当前诊断。正常完成没有技术复制按钮。复制失败在原按钮上提示重试，窗口不关闭，不触发递归报错。正确恢复此前模态窗口的grab与焦点。

规则异常和预览失效在弹窗打开前更新记录。所有跳过的非发票文件在完成弹窗中可滚动查看，替代旧的最多8项加详情入口，避免移除详情后丢失清单。中文摘要不再指向不存在的详情入口，恢复未完成等关键处理建议继续保留。

保持V1.1.21，只更新本地，保留私人签名和共享识别规则，不改Excel/PDF及金额判断。本轮未请求测试，不新增/运行测试；完成独立静态复查、语法、Windows构建及保存文件/公开包核对，明确未运行GUI交互验证。
