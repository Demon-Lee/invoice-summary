# 可同步的模板最低保留行规则

用户已确认 skill 的动态保留规则，并授权继续更新软件。沿用已批准的功能边界：共享规则控制模板最低保留行；人工校正、清空主表旧业务明细、提示和恢复由软件管理。

## 方案

在 skill 的 scripts 目录增加 `template_rules.json`，由 skill 写表器和桌面软件共同读取。规则声明侧边完整标识、忽略的标点和允许的排列方式；规则算法为定位完整标识的实际最后一行。软件支持单格整句和同列连续分段，不能把行号写死。相比继续复制文字说明，共用规则文件可真正随快照导入；相比把整个 Node 写表器搬进软件，避免新增 Node 与 artifact-tool 桌面依赖。

软件按 max(表头行 + 本次明细数, 标识实际结束行) 保留明细区；其后为合计、签字、说明。必要空行保持样式、边框和行高且内容为空，合计包含保留区。源模板的合计已经在标识结束行或其上方时停止并报告实际行号，与当前 skill 一致。

主表边界包括覆盖表头的合并范围终列。Node 读取的矩阵从 A1 建立绝对坐标，不把 used range 相对索引作为实际行号。共享声明 `label_value_source: literal-cells` 要求右侧内容为固定值；双方遇到右侧公式均报告坐标并停止，避免读取结果／公式文本不同而静默漏掉可见标识。JSON schema 数值等于 1（含 1.0）有效，布尔值无效。

规则包格式 3 包含新 JSON 和模板规则接口版本 1。格式 1/2 的已有四文件快照继续可读；它们没有最低保留规则，沿用旧行为，回退也保持快照行为。已知旧写表器指纹与本次共用规则写表器指纹明确受支持；未知写表器变化仍要求升级。新规则文件的配置改动可直接同步，未知策略、字段或接口版本拒绝导入。

软件默认引擎保持旧版，用户可在新版软件手动同步已更新的本机 skill，观察规则版本及模板规则更新结果。同步后的整个软件文件夹携带 JSON，接收方无需 skill。旧更新包可以导入、回退和分发；快照版本纳入新规则文件及范围声明。
