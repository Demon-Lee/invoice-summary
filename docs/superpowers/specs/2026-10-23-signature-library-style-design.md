# 1.1.22 发布前补充：签名库界面

用户在1.1.22打包期间要求先优化签名库界面，再上传GitHub。版本号仍为1.1.22，暂不创建远端标签/Release或推送，待此界面修改与重新构建结束后一起发布。

签名库沿用主界面的白色卡片、灰色页面和蓝色圆角操作。按用户后续截图要求，取消页内重复的签名库标题、格式提示及其整条容器；导入、打开文件夹、刷新作为一组工具直接接在页签下，不保留被删标题的空白。内容默认分为左侧签名列表和右侧居中预览两张卡片，窄窗口上下排列。重命名、替换、删除集中在内容下方，删除用红色文字区分。工具栏按实际按钮尺寸和可用宽度换行，不截短文字。现有警告保持可见并继续同步到签字位置页。

只重排signature_ui.py中的签名库控件，调整预览说明的换行宽度到预览卡自身宽度。不修改任务、缓存、读取/变更、角色草稿、保存/关闭、对话框定位或PDF行为。切换页签/调整窗口大小不新增扫描或图片任务。继续使用既有列表和画布，保留自动隐藏滚动条及刷新选择/滚动恢复。

保持原发布任务的私人数据与识别规则基线，显式将signature_ui.py加入本次允许修改范围，其他模块仍逐字节保护。用户未请求测试，仅做静态复核、语法、构建、保存代码/压缩包及上传完整性检查，不启动GUI/Excel。公开包排除整个个人签名目录，本机原软件需要关闭后才能更新；当前关闭提示已发出。
