# 导出签名窗口风格统一

用户认可直接选择并记住人选的功能，要求新界面与主界面统一，尤其优化老式滚动条。保持1.1.24及全部选择、保存、预览、取消语义。

代码检查确认导出页面外层已使用主界面的AutoHideScrollbar，但原生Combobox展开列表使用Tk自带的带箭头Scrollbar，且不继承关闭状态选择框样式。

## 展示方案

- 关闭状态选择框采用与签名管理相同的浅色字段、平面细边框、蓝色悬停/焦点状态。
- 展开列表使用主界面字体、白色底色、浅蓝选中行及深色文字，弹出容器用细边框。
- 列表右侧原生滚动条保留原滚动机制，局部样式移除上下箭头，宽度8px，使用灰蓝滑块，悬停/拖动加深；空闲1400ms后隐藏滑块和轨道的颜色。保留固定宽度，不因显示/隐藏改变列表宽度。鼠标活动、键盘和滚动时重新显示，鼠标停在滑块上或拖动期间保持可见。
- 只对导出窗口四个选择框安装局部弹出样式，不改写Tk内置脚本、全局TScrollbar或其他界面；不修改业务、签名库和异步任务。
- 保留点击/键盘选择、Escape和点击外部关闭，关闭状态滚轮不换人。导出窗口右侧继续使用既有细线自动隐藏滚动条。

静态复查、纯语法、构建及成品字节核对，不新增或运行测试/GUI/实际导出。保留私人签名与规则，更新本机原目录并保留旧目录备份；公开包排除私人目录及业务文件。保持1.1.24，不上传GitHub。
