# 执行完成后启用 PDF 导出

用户已确认：执行处理成功后才启用导出，更换输入或重新预览后再次禁用。软件版本1.1.13，取代直接选择已有工作簿即可导出的界面流程。

## 状态规则

启动、仅选择输入、预览中／预览完成、校正后、执行失败、无需处理均不可导出。Controller 返回 completed（已经逐票及批次金额核对通过）后，App 在后台记录本次输入路径、识别版本与完成工作簿哈希，允许导出。金额通过但临时文件清理有提醒仍可导出；若完成文件哈希无法读取，仅禁止导出并说明原因，不误报填表失败。

输入变更被接受、实际开始新的预览／校正／执行、已激活规则更新或重启软件后撤销资格。取消操作或拒绝清除校正不撤销原资格。导出取消、普通导出失败和成功不撤销，允许重试及重复导出；无关操作失败且输入／规则未变时也保留资格和原报告。3秒来源检查、导出入口及模态确认后核对实际规则版本，覆盖另一软件窗口激活更新的情况。100ms状态刷新只比较内存资格与当前输入字符串，不读取文件系统。

## 导出门禁

按钮启用和实际点击入口共用资格检查；选择导出位置及覆盖确认后再次核对资格未变化。后台在稳定工作簿快照建立时检查哈希仍匹配本次完成版本，防止确认弹窗期间或导出前被其他程序修改。失配／文件丢失时停止输出，撤销资格并提示重新预览、执行。其他导出失败保留资格以便重试。

主操作提示、成功／失败报告、导出设置弹窗、软件功能归属及使用说明明确完整顺序：只读预览 → 可选校正 → 执行处理及金额核对成功 → 导出 PDF。打开已有导出目录功能独立保留。
