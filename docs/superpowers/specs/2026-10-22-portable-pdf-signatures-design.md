# PDF 签名与便携保存设计

## 已确认需求

用户在软件中手动导入签名图片；只在导出的 PDF 中添加签名，原 Excel 不出现签名。四处签字位置使用统一的尺寸标准，按最小可用签字区域约束。导入后的图片和配置存放在软件目录内，随整个目录复制后继续使用。

## 界面与操作

- 主界面新增一个“签名设置”按钮，打开独立小窗口；不增加选项卡。
- 设置窗口分为验收单“经办人、验收人”和领用单“保管人、领用人”四个位置。每处显示已保存图片预览，并提供“导入／更换图片”和“清除”操作。支持 PNG、JPG、JPEG。
- 各位置分别保存配置；同一人需要出现在多处时，可以为多个位置导入同一张图片。未配置的位置留空。
- 导出窗口提供“添加已保存签名”勾选项。存在已保存签名时默认勾选；未保存任何签名时默认不勾选，并可进入签名设置。用户也可取消勾选，正常导出无签名 PDF。
- 处理中禁止更改签名；导出开始前为本次操作固定签名图片和配置快照。

## 便携保存

目录结构：

```text
InvoiceSummary/
  InvoiceSummary.exe
  _internal/
  recognition/
  signatures/
    config.json
    images/
```

- 导入时将实际图片复制到 signatures/images，并保存软件目录内的相对路径；不依赖导入照片的原路径。
- 删除原照片、重启软件或移动整个软件目录后，已保存签名仍可使用。
- 配置只记录四个位置的图片映射及格式版本；不保存本机绝对路径。
- 本地维护升级保留已保存的签名目录；个人转移时复制整个 InvoiceSummary 文件夹即可。
- Git 忽略个人签名目录，正式发布源码包和 GitHub 软件包排除个人签名文件；接收者在自己的软件中导入。打包排除规则不得删掉本机签名。

## 定位与统一尺寸

- 四处分别根据“经办人、验收人、保管人、领用人”及其对应签字行动态定位，跟随明细增减，不写死第几行或页面坐标。
- 签字区域是标签后方、下一标签或日期前方的可用空白，扣除边距，不将标签本身计入可用空间。
- 以最终 PDF 中四处可用区域计算共同尺寸：共同宽度不超过各处可用宽度的最小值，共同高度不超过各处可用高度的最小值。计入两张表各自的打印缩放，保证 PDF 中采用相同标准。
- 图片去除外围可识别的空白后，保持原长宽比例放入共同尺寸框；签名居中显示，不拉伸笔迹。不同姓名的自然长宽可以不同，统一的是可用框和适配规则。
- 使用轻微内边距，避免覆盖标签、日期、单元格边框或其他已存在内容。
- 四处都参与尺寸计算，即使只导入一部分签名，也不会因为配置数量变化而改变统一尺寸标准。

## 导出边界与处理方式

采用现有 Excel 导出流程生成排版，再在软件的 PDF 输出处理阶段完成签名定位与加入。这样可以依据实际 PDF 尺寸统一比例，并保留已有 A4 横向、所有列一页宽、明细自动分页的约定。另一种方式是在临时 Excel 副本中放图片再导出，但仍需额外处理两表打印缩放；本设计优先采用 PDF 输出层。

- 不在原工作簿保存图片、绘图对象或签名文字；导出前后继续核对原工作簿指纹。
- 不改 skill、发票识别、主表写入、金额复核及“执行成功后才允许导出”的门禁。
- 签名只放在实际签字栏所在页，不在其他明细页重复盖图。
- 已配置图片丢失或不可读、签字区域不唯一或空间不足时，带签名导出明确停止并说明原因；不能悄悄漏签或覆盖正文。用户可以修正设置，或明确取消添加签名后按原流程导出。
- 两份 PDF 完成签名和有效性检查后才发布，继续使用现有成对替换／失败恢复流程。
- 签名照片的导入不修改原图片文件。

## 模块职责

- 签名存储模块：图片导入、校验、相对路径配置、清除及导出快照。
- 签名设置窗口：四处配置、导入按钮、缩略图及状态提示。
- PDF 签名模块：动态定位、四处共同尺寸计算、等比例放置和输出检查。
- PDF 导出集成：勾选状态、快照传递、错误及报告、原有发布与恢复逻辑。
- 构建与打包：本地升级保留个人配置，公开归档排除个人图片。

## 可观察的完成条件

1. 四个位置均可通过按钮导入、替换和清除图片；再次打开软件仍可看到保存内容。
2. 删除导入源图片并移动整个软件目录后，签名配置仍有效。
3. 带签名 PDF 对应位置正确，原 Excel 文件字节不因本次导出改变。
4. 明细较少、较多或跨页时，签名随签字行移动，仅出现在签字页。
5. 四处采用同一尺寸框；不遮挡标签或日期，笔迹比例不变。
6. 未配置、取消添加签名时仍可正常使用原 PDF 导出。
7. 带签名导出失败时保留原有 PDF，并说明无法处理的具体位置或图片。
8. 公开软件包、源码包与 GitHub 中不包含用户导入的签名。
