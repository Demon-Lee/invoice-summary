# 首次预览提示与冗余文字删除

用户指出首次选择PDF文件夹、工作簿后不应显示“需要重新预览”，并要求删除三个主操作按钮同行的全部辅助小字、品牌标题下“先预览，再执行 · 逐分复核金额”副标题。依用户明确要求实施1.1.17。

根因是两个路径的write trace均调用_invalidate，其中阶段标题和底部状态无条件使用“需要重新预览”。新增会话内_has_previewed，初始False，只有_render_preview接受预览结果时置True；_invalidate据此分别显示“等待只读预览”或“需要重新预览”，底部状态一致。重启不继承预览历史；未返回有效结果的失败不算完成预览。

ui.py删除副标题、action_hint控件及绑定；app.py删除其全部动态刷新与仅供提示使用的局部变量。按钮、导出资格、路径锁定、校正和业务逻辑不变。版本及说明同步1.1.17。仅静态编译／独立复审、构建及包完整性核对，不新增或运行测试、GUI、Excel或业务流程。本地归档旧版并替换原目录；运行中的旧版等用户关闭，不结束用户进程；不上传GitHub。
