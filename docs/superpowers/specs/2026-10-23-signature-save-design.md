# 签名管理文字精简与位置保存

用户直接指定本轮交互：删去签名管理标题下的“文件名即标签……”；将底部关闭按钮改为保存，签字位置仅在点击保存后生效；右上角关闭丢弃未保存的位置选择。签名库标题后显示“签名格式仅限PNG/JPG/JPEG”，删去底部格式长提示。主界面删去“离线处理”和“打开位置”。

位置选择使用窗口内草稿，保存通过现有后台任务一次提交全部已修改位置，沿用签名库锁、版本检查及原子配置写入，避免四次单独保存导致部分提交。保存成功保留窗口并显示简短状态；关闭和Escape不提交草稿。图片导入、改名、替换、删除继续通过签名库原有文件操作提交。

刷新、导入和改名保留仍有效的草稿；图片删除或指纹变化使相关草稿失效并标记该位置需确认，不能静默改用其他签名。并发变化或保存错误保留草稿，要求刷新核对。保存已成功但随后读取失败时提示已保存并要求刷新，不提示全部失败。

沿用当前V1.1.21，在现有功能分支实现，仅更新本地软件。保留私人签名和识别规则；不改识别、写表或PDF算法。本轮用户未要求测试，按会话开发约束不新增或运行测试；进行静态复查、语法编译、构建及产物完整性核对，并明确未运行交互验证。
