# 执行步骤与必要条件设计

用户希望使用者首先了解执行步骤和必要条件。本次请求授权完成界面调整和重新分发，不再增加确认环节。

## 界面与文案

在默认“处理发票”页的文件选择之前加入两个并排的说明区。执行步骤用浅蓝底、醒目标题和四步编号；必要条件用浅黄底、醒目标题和四条要求。内容分别说明选择文件、只读预览、执行处理、检查结果，以及 Windows/Excel、文本 PDF/完整批次、规定格式的工作簿和文件权限。颜色之外也使用明确标题和编号。

两区下方单独标明实际执行会重命名 PDF、原位更新工作簿且不自动备份。说明区随窗口宽度换行，保留可伸缩明细表和滚动条。结果框适当缩短，窗口最小高度调整为 760，以容纳新增说明。

“使用说明”页以“执行步骤”“必要条件”开始，标题使用更大字号和加粗。发布包的使用说明及 README 同步调整，详细的模板要求和维护者规则更新说明仍可查看。
