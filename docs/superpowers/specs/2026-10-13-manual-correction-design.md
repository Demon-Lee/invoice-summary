# 软件内人工校正设计

用户明确要求只在软件加入轻量明细字段校正，不修改 skill。漏项、多项、无法解析整票等识别结构问题继续通过改进 skill 解决。本请求已授权实现与更新现有分发目录。

## 操作范围

预览表新增产品名称、生产厂家、自动单价和校正标记。双击明细或点击“人工校正”，弹窗同时展示原始识别值和当前值。可改产品名称、规格型号、单位、数量、含税金额、生产厂家；单价自动计算。弹窗提供保存并检查、恢复识别值、打开原发票和取消。

行数、行序、发票序号、PDF 内容、票号和票面总额固定。校正不能删除异常、添加或删除明细、手动改文件名。软件按第一条有效产品名称重新生成标准改名计划。

保存仅更新本次预览，不改 PDF、Excel 或 skill。重新检查所有未解决解析异常、每票及批次金额、模板、已有明细映射、文件哈希和改名碰撞。校正数值须合法，金额精确到分，每票校正后的明细合计仍须等于原始票面总额。数量空白按 1，非空必须是非零有效数字；名称和生产厂家不能为空，规格和单位可空。

## 已有明细与恢复

原位写表只允许更新人工明确校正的既有行，且既有业务字段须与原识别值或当前校正值一致。其余工作簿冲突继续阻止执行，不能用校正功能强制覆盖未知内容。保留重复明细、原顺序、备注、公式与页脚。

本次预览中的校正可多次调整或恢复。重新发起普通预览会重新识别，需要重新校正。为防止执行中断丢失校正，未完成运行记录包含本次校正及发票身份、顺序；恢复时核对识别版本和 PDF 哈希，再从实际文件重新取得原始字段，恢复校正。未完成运行中的校正固定，先完成该次运行再开启新预览校正。记录只保存在本机 AppData，不随软件包分发。
