# 1.0.0 用户体验收尾

用户已批准上轮提出的四项改进：保护人工校正、报告可读与复制、规则问题给出正确下一步、整理普通用户与维护者说明。按已批准方案执行并发布 1.0.0。

## 行为

1. 有人工校正时，重新预览按钮及明细提示明确说明会清除校正；只有用户确认后才重新识别。取消保留原预览和校正。规则更新、关闭等会丢弃本次校正的操作同样针对实际校正提醒；普通无校正操作不弹此提醒。失败操作不无故丢弃仍有效的原预览。
2. 预览异常放在报告开头，执行失败原因放在已执行步骤之前。报告及说明提供可见垂直滚动条，主报告增加复制按钮，复制完整原文且不更改发票或工作簿。
3. 来源状态使用软件端明确分类：当前、发现更新、来源不可用、来源内容需修正、接口不兼容、说明尚未实现。相应提示分别指向同步、重新选择／解除绑定、修正规则或适配软件，不将所有问题都说成“先同步”。检查来源异常时可保留当前预览但停止执行；实际更换输入或激活新规则仍要求重新预览。
4. 普通使用者完整解压即可用随包规则，无需安装或同步 skill；维护者负责规则同步与整文件夹分发。清理“默认旧引擎、等待试同步”等开发阶段表述。界面、使用说明、README 与功能边界一致。

## 保持的要求

Microsoft Excel 桌面版、完整批次重填、六字段人工校正、不自动备份、保留模板文字和可同步最低保留行规则均沿用。当前共享规则 6b9e6cdafb3f 及上一版快照保持，不修改 skill、业务文件或识别／写表算法。不加入路径记忆、小屏适配或新校正字段。

## 交付与核对

采用 Python 静态语法编译、独立源码审查、Windows 构建、发布清单与 ZIP 核对；依开发约束不新增或运行测试，也不启动业务处理或 GUI。发布至原 release/InvoiceSummary，旧软件文件夹归档，产生 1.0.0 Windows 与源码包。
