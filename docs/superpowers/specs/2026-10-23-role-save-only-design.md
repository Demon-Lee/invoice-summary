# 保存只出现在签字位置

用户确认保存按钮在签字位置有用，要求签名库无用时删除并缩小界面。现有保存函数仅提交pending_bindings；图片导入、重命名、替换和删除已由各自变更任务提交。因此只在签字位置显示同一保存按钮，签名库隐藏该按钮。保存对象、草稿与文件操作不变。

签字位置保留底栏；签名库空闲且状态为空时收起底栏，有正在读取/保存、失败或未提交位置等状态时仅显示简短状态。统一状态更新入口同步底栏可见性；页签切换只改变呈现，不提交数据。将默认窗口高度上限从700缩小到640，仍保留原最小尺寸、用户缩放及自动隐藏滚动条。

版本保持1.1.22，GitHub继续等待用户明确预览批准，不推送/上传/发布。保持签名图片及配置、识别规则、engine/skill和处理流程。未请求测试，不新增/运行测试；仅静态复核、语法、构建和保存文件核对。原程序关闭后更新原目录，供用户继续预览。
