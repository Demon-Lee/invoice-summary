# 导出窗口直接选择并记住签名

## 已确认的需求

用户希望在导出 PDF 的确认窗口直接更换经办人等签字位置的人选，并明确选择“自动记住，下次导出也使用这次的人选”。沿用四个位置：验收单经办人、验收人，领用单保管人、领用人。

## 交互

- 导出窗口以两张卡片展示四个位置，默认带入签名管理已保存的选择。每个位置有只能选择的下拉框和对应的签名图片预览，也可明确选择不使用签名。
- 点击开始导出时一次保存四个位置，并固定本次使用的图片快照。取消、Escape 或关闭窗口不提交位置选择。保存后即使后续 PDF 导出失败，人选仍作为下次默认值。
- 继续保留添加签名开关及签名管理入口。关闭添加签名时无签名导出，不提交隐藏的位置修改。
- 鼠标滚轮不能切换下拉框人选。读取和图片预览使用现有后台队列，过期图片不展示；保存期间禁止关闭和继续编辑。
- 刷新或从管理窗口返回时，仅保留图片身份及内容均未改变的待选项。已删除、替换或存在待确认状态的签名，必须重新选择标签或明确不使用；不能静默导出成无签名。
- 颜色、卡片和按钮沿用主界面风格。窗口居中，小屏幕仅在内容实际溢出时显示滚动条，操作按钮始终可见。

## 保存边界

SignatureStore 新增 save_export_selection(bindings, expected_revision=None)，要求完整四位置映射。在同一签名库锁内重新读取库、核对显示版本、检查全部人选、读取并校验所选图片、创建不可变快照，然后原子保存选择并返回该快照。图片不可用或保存失败则窗口保持打开，不开始导出。原 snapshot API 的行为保持。

导出窗口只维护未提交草稿；签名库的文件名、存储格式、管理窗口的保存操作、共享 skill、识别规则、Excel 排版及 PDF 绘制流程不变。签名只进入 PDF。

## 交付与核对

本地版本为 1.1.24。只更新本机便携软件，保留原目录备份及原有私人签名、配置和识别规则。公开压缩包排除整个 signatures 目录及业务文件；上传在用户另行要求时进行。

本次仅做静态审查、语法编译、Windows 构建与成品/压缩包字节核对。不新增或运行测试，不操作用户发票、业务工作簿或现有私人签名库，不将静态检查表述为界面或实际导出已验证。
