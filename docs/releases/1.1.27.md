# V1.1.27 · PDF 明细行距优化

- 验收单和领用单按各行文字所需的高度排版，减少单元格内上下留白。长文字自动换行，表头和模板空行保留原有行高要求。
- 验收单按更接近实际打印列宽的方式测量行高，减少厂家名称等文字导致的多余空白。若导出结果出现文字裁切或分页不符，软件会按较宽松的行高自动重试，核对通过后才保存文件。
- 签字及日期继续预留空间。最后一条明细和合计、签字、日期、说明保持同页。紧凑排版应用于 PDF 导出的临时副本。

同一份样张在 WPS 中的验收单从 4 页减到 3 页，领用单从 3 页减到 2 页。Excel 中部分明细行也更紧凑，样张页数保持原样。两种表格软件都完成了带签名的实际导出检查。

Windows 用户下载 **InvoiceSummary-1.1.27-Windows.zip**，完整解压后运行 **InvoiceSummary.exe**。需要 WPS 表格或 Microsoft Excel 桌面版。如需沿用个人签名，将原软件旁的 `signatures` 文件夹复制到新版目录。**InvoiceSummary-1.1.27-Source.zip** 为对应源码，**SHA256.json** 提供两个压缩包的校验值。
