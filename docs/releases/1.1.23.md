# V1.1.23 · WPS 表格兼容

## 本次更新

- 自动优先使用 WPS；无法启动可用的独立 WPS 实例时，在处理开始前尝试 Microsoft Excel。
- 本次执行与 PDF 导出使用同一种表格软件，处理中失败会提示原因。
- 保留自动列宽、公式重算与金额核对、A4 横向一页宽、末项及页脚同页、PDF 签名和完整性检查。
- 修复部分 PDF 成对边框引起的单元格定位误报，文字完整性检查标准保持不变。
- 修复 WPS 将空白保存为空字符串、将明细单价保存为15位有效数字后引起的排版核对误报。数量、金额、公式、非空文字及合并结构仍严格比较，其他单元格不适用单价精度豁免。
- 导出PDF时打印区域左右居中，左右页边距对称；仅修改导出副本，不回写原工作簿。

## 下载与使用

- 普通用户下载 **InvoiceSummary-1.1.23-Windows.zip**。需要 Windows 10/11 和 WPS 表格或 Microsoft Excel 桌面版，完整解压后打开 InvoiceSummary.exe。
- **InvoiceSummary-1.1.23-Source.zip** 为对应源码；**SHA256.json** 用于核对两个压缩包。
- 已实测 WPS 12.1.0.29161（2026 秋季更新，32 位）。其他版本需试用确认。
- 更新前退出旧软件，迁移个人软件时保留整个 signatures 文件夹；公开分发包排除签名、发票和业务工作簿。

此前已用临时副本验证 WPS 和 Excel 的标准模板填表及四处模拟签名导出，以及 WPS 多页和末尾分页；未修改实际发票、工作簿或个人签名。旧单元测试存在与已发布版相同的14项失败/错误，新增兼容与边框回归检查通过。新增页面左右居中设置仅完成静态、语法、构建及成品核对，本轮未实际导出验证。
