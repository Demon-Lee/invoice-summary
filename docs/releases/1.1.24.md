# V1.1.24 · 导出窗口直接选签名

## 本次更新

- 导出窗口可直接选择验收单经办人、验收人及领用单保管人、领用人的签名，每处显示图片预览。
- 点击“开始导出”时统一保存四处人选，下次导出和签名管理自动沿用。点击取消、Escape 或关闭窗口不保存位置草稿。
- 保留“添加签名”开关、各位置“不使用签名”和签名管理入口。下拉框滚轮不会切换人名。
- 读取及预览在后台完成；保存前核对签名库版本和所选图片，构造本次快照后再保存选择。保存失败不开始导出，签名库在其他窗口或文件夹变化时需要重新确认。
- 窗口沿用主界面配色，操作按钮固定底部；内容超出可用区域时才允许滚动。

## 使用与验证范围

- Windows 10/11，安装 WPS 表格或 Microsoft Excel 桌面版。完整解压运行 InvoiceSummary.exe。
- 转移个人软件时保留整个 signatures 文件夹；公开压缩包排除私人签名、发票及业务工作簿。
