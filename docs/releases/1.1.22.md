# V1.1.22 · 界面与签名管理优化

## 本次更新

- 主界面七个按钮共用一行，以分隔线区分“预览—执行—导出”三步流程和四个辅助功能；窄窗口自动换行。
- 签名管理改为扁平页签，默认显示签字位置。验收单、领用单各使用一张卡片，并排设置两个签名；签名库保留导入、刷新及图片管理。
- 切换签名页签保留草稿与滚动位置，仍需点击“保存”才提交签字位置；关闭不保存未提交的选择。
- 正常完成不再弹窗，异常及跳过文件等提醒仍可查看；移除主页面详情区域，为发票明细留出空间，异常弹窗支持复制完整错误信息。
- 提示、确认、校正、签名和导出设置统一以主窗口居中定位。

## 下载与使用

- 普通用户下载 **InvoiceSummary-1.1.22-Windows.zip**，完整解压后运行 InvoiceSummary.exe。需要 Windows 10/11 和 Microsoft Excel 桌面版。
- Source.zip 为对应源码；SHA256.json 用于核对两个压缩包。
- 更新前退出旧软件；需要迁移已导入的签名时，请保留旧软件旁的整个 **signatures** 文件夹，放到新软件对应位置。
- 公开软件包和源码包不含个人签名、发票或业务工作簿，历史版本继续保留。

本版完成静态复查、语法编译、Windows构建和保存文件/压缩包完整性核对；本轮未运行GUI、Excel或实际PDF导出测试。
