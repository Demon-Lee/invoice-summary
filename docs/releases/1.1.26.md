# V1.1.26 · 发票汇总与 PDF 排版

- **发票汇总 PDF**：导出时可同时生成 `发票汇总.pdf`，默认开启。已处理的发票按明细序号排列，一张发票有多条明细时只合并一次，多页发票保留全部页面。汇总文件与验收单、领用单保存在同一目录。
- **导出界面**：导出位置、导出内容和签名分成三个区域。待导出文件以卡片展示，切换汇总开关时更新清单。
- **表格排版**：产品名称、规格和厂家等长文字在 A4 横向页面内自动换行。两处签字、日期标签和日期值预留空间，日期单行显示，四处签名按最小可用区域等比例适配。最后一条明细、合计、签字和说明留在同一页。长表可能增加页数，排版设置只应用于导出副本。
- **批量改名**：当一个目标文件名将在本批中由另一张发票腾出时，可继续按序号整理。对真正的重名冲突仍会停止，避免覆盖现有文件。
- **多页发票识别**：逐页读取明细，并在预览中核对明细与票面含税合计，金额不符时阻止执行。

## 下载

Windows 用户下载 **InvoiceSummary-1.1.26-Windows.zip**，完整解压后运行 **InvoiceSummary.exe**。需要 WPS 表格或 Microsoft Excel 桌面版。升级时可将自己原有的 `signatures` 文件夹复制到新软件目录，继续使用签名和签字位置配置。

**InvoiceSummary-1.1.26-Source.zip** 为对应源码，**SHA256.json** 提供两个压缩包的校验值。
