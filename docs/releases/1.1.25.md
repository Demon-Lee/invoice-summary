# V1.1.25 · 导出签名选择与界面优化

发布日期：2026-11-12。

本版汇总此前 V1.1.24 本地预览阶段的签名选择与界面改进，作为正式下载版本发布。以下变化相对于 GitHub 上已发布的 V1.1.23。

## 1. 导出窗口直接更换签名

- 导出 PDF 时，直接在窗口中选择验收单的**经办人、验收人**，以及领用单的**保管人、领用人**。
- 每个位置使用已有签名库的标签下拉列表，并展示对应签名图片，便于核对标签与字迹。
- 默认带入上次保存的人选；同一签名可以用于多个位置，各位置也可单独选择“**不使用签名**”。
- 导出窗口保留“签名管理”入口，可进入管理窗口导入、替换或整理图片。

## 2. 开始导出时记住人选

- 点击“**开始导出**”时统一保存四个位置的选择。下次导出及签名管理自动沿用这些人选。
- 点击取消、Escape 或右上角关闭，不提交当前导出窗口里尚未保存的人选改动。
- 关闭“添加签名”后生成无签名 PDF，不提交隐藏的位置改动，之前已保存的人选继续保留。
- 全部位置都明确选择“不使用签名”时，可保存这组选择并生成无签名 PDF。
- 人选在开始导出时保存：如果后续 PDF 生成失败，已保存的人选仍然保留，重试时可继续使用。

## 3. 签名预览与选择检查

- 读取签名库、生成预览和提交人选使用后台任务，快速切换时丢弃过期预览。
- 缩略图根据位置框的实际可用宽度缩放；相同图片按内容指纹和尺寸复用预览。
- 保存前重新核对签名库版本及所选图片的实际内容，在同一签名库锁内先构造本次导出的不可变快照，再原子保存人选；核对或保存失败时保留窗口供处理。
- 图片被外部删除、替换或改名后，受影响位置需要重新选择标签，或明确选择不使用签名。
- 已发现失效的草稿不会因文件后来恢复成旧内容就自动重新生效，仍需用户点选确认。
- 修正了“请重新选择”等占位文字与真实标签重名时可能被误认为有效选择的边界。
- 保存期间禁用继续编辑和关闭操作，避免误以为已取消正在进行的保存。

## 4. 人名下拉列表统一样式

- 选择框采用浅色背景、平面细边框和蓝色焦点/悬停反馈，与主界面配色一致。
- 展开的人名列表采用主界面字体、白色背景、浅蓝选中行及深色文字。
- 右侧滚动条改为 **8px 无上下箭头的灰蓝细滑块**，悬停或拖动时颜色加深。
- 空闲约 **1.4 秒**后隐藏滑块和轨道颜色；鼠标活动、键盘或滚动时重新显示，悬停或拖动滑块期间保持可见。
- 隐藏前后保留相同宽度，避免列表内容左右跳动；列表不溢出时由原生控件收起滚动条。
- 下拉框关闭时，鼠标滚轮不会切换人名；展开后可正常滚动列表，仍可点击或用键盘选择、按 Escape 关闭。

## 5. “添加签名”改为圆角开关

- **蓝色表示开启，浅灰表示关闭**；禁用时颜色减淡。
- 增加悬停、按下和键盘焦点外观，使用与主界面一致的缩放绘制方式。
- 点击开关或“添加签名”文字均可切换，也可用 Tab 定位后按空格操作。
- 开关继续控制四个签名位置的可用状态和是否在 PDF 中添加签名。

## 6. 导出窗口布局

- 验收单、领用单使用两张白色卡片，每张卡片包含两个签字位置和对应预览。
- “开始导出”“取消”固定在底部；内容超出窗口可见区域时才允许滚动，外层沿用细线自动隐藏滚动条。
- 窗口初始尺寸受主窗口所属屏幕的可用区域约束，并在主窗口上方居中打开。
- 构建附带的第三方说明同步到实际依赖版本，包括 Pillow 13.0.0。

## 使用示例

1. 完成只读预览和执行处理，点击“导出 PDF”。
2. 如需更换经办人，在“验收单 → 经办人”直接选择新标签，核对下方签名图片。
3. 检查其余三个位置及输出目录，点击“开始导出”。选择会被记住，下次自动带入。
4. 这次不需要签名时，关闭“添加签名”后导出；需要撤销本窗口的改选时，点击取消。

## 下载、更新与签名迁移

- 普通用户下载 **InvoiceSummary-1.1.25-Windows.zip**，完整解压后运行 **InvoiceSummary.exe**。
- 需要 Windows 10/11 和 WPS 表格或 Microsoft Excel 桌面版；软件优先使用 WPS。
- **InvoiceSummary-1.1.25-Source.zip** 是对应源码，**SHA256.json** 用于核对两个压缩包。
- 更新前退出旧软件。迁移个人软件时，将旧软件旁的整个 **signatures** 文件夹保留到新软件对应位置；人选配置和签名图片都在其中。
- 公开软件包和源码包不含个人签名、个人签名配置、发票或业务工作簿。签名仅添加到导出的 PDF。
